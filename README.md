# 🛒 Grocery Inventory System

A console-based **Java application** to manage grocery store inventory efficiently.

## ✨ Features
- Add grocery items with quantity and price.
- Sell items and update stock.
- Generate unique item IDs starting from G101.
- Display items alphabetically using Bubble Sort.
- Generate low-stock reports (quantity below 5).
- Save and load inventory using `inventory.txt`.

## 🛠️ Technologies Used
- Java
- ArrayList
- HashMap
- Bubble Sort
- File Handling

## 🚀 How to Run

```bash
javac GroceryInventorySystem.java
java GroceryInventorySystem
```
